## 🌟 Overview

**SpaceBunny Chat** is an interactive, high-precision AI assistant powered by `stealth/space-bunny-alpha` (1M context window via OpenRouter). Built with a modern dark-themed aesthetic, dynamic 3D visual effects, and integrated search capabilities, SpaceBunny delivers exact, contextual responses while disambiguating complex user prompts.

🔗 **Live Application:** [https://mint-gpt.netlify.app/](https://mint-gpt.netlify.app/)

---

## ✨ Features

- **🧠 SpaceBunny Alpha Reasoning Engine:** Equipped with a 1M token context window for deep analysis, code generation, and complex problem-solving.
- **🌐 Real-Time Web & Map Search:** Integrated Web Search and Google Maps capabilities for live contextual information retrieval.
- **🌌 Interactive 3D Space Core:** Built-in dynamic canvas background bringing an immersive spatial theme to the workspace.
- **🎙️ Natural Voice Narration:** Integrated text-to-speech engine allowing users to read aloud responses with natural AI voices.
- **🔐 User Authentication:** Seamless sign-in support via Google Authentication.
- **⚡ Hotkeys & UX:** Keyboard shortcuts (e.g., `Ctrl+K` for new chat, `Shift+Enter` for multi-line inputs) designed for an effortless workflow.

---

## 🛠️ Tech Stack

- **Frontend Framework:** JavaScript / React (or HTML5/CSS3)
- **3D Graphics:** WebGL / Three.js (3D Space Core)
- **AI Integration:** OpenRouter API (`stealth/space-bunny-alpha`)
- **Hosting & Deployment:** Netlify

## 🚀 Getting Started

To run this project locally, follow these steps:

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/your-username/spacebunny-chat.git](https://github.com/your-username/spacebunny-chat.git)
   cd spacebunny-chat
Install dependencies:

Bash
npm install
Set up Environment Variables:
Create a .env file in the root directory and add your API keys:

Code snippet
VITE_OPENROUTER_API_KEY=your_openrouter_api_key
Start the development server:

Bash
npm run dev
Open your browser and navigate to http://localhost:5173.

📖 Usage
Ask Anything: Enter complex math, architecture, or code requests directly into the prompt box.

Disambiguation: If your prompt is broad or ambiguous, SpaceBunny will automatically break down exact scenarios to ensure precise answers.

Read Aloud: Click the Read Aloud button on any message to trigger natural AI speech synthesis.
